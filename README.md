# Material Registration Automation with AutoHotkey

Script developed with AutoHotkey v2 to automate the registration of materials in a web application. It uses arrays to manage codes, quantities, and values, automatically executing data entry, tab navigation, timeouts, and page scrolling.

For each new registration, only the quantities array needs to be updated, leaving the main automation logic unchanged.

This app helps to automatize and optimize personal time, before you need to write each one from excel to the web page. Now, you can save time with this automatic code, it was powerful to reduce job from 6 hours to 30 min aprox.
